# Cowrie credential database for corp-webapp-01.
# Format: username:x:password  (a leading ! negates, /regex/ matches a pattern).
#
# Deliberately curated instead of using cowrie's shipped example, which accepts
# any password for root via a wildcard and ships a demo user 'phil'. Both are
# well-known cowrie fingerprints, and 'phil' is not present in /etc/passwd here.
#
# We accept the planted decoy admin credential plus a set of common weak
# passwords for root, so opportunistic brute-force attempts still land in the
# honeypot without advertising the "any password works" tell.
